Quelle eintragen

Google Docs verbinden (einmalig, 5 Minuten)

1. script.google.com öffnen, neues Projekt.
2. Den Script-Text (Knopf unten) komplett einfügen, Beispielcode vorher löschen.
3. Im Script bei TOKEN ein eigenes Passwort eintragen.
4. Oben rechts "Bereitstellen" > "Neue Bereitstellung" > Typ "Web-App", Ausführen als "Ich", Zugriff "Jeder" > Bereitstellen, Zugriff erlauben.
5. Die Web-App-URL (endet auf /exec) und das Passwort hier in den Einstellungen eintragen.

Danach legt "Google Doc" im Quellen-Tab pro Projekt ein Dokument im Drive-Ordner "VideoGrab Quellen" an und aktualisiert es bei jedem Export. Teammitglieder können dieselbe Adresse und dasselbe Passwort eintragen, dann landen ihre Docs in deinem Drive.
